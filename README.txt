MYFIT 1.0 — ПЕРСОНАЛЬНОЕ PWA

1. Демонстрация на компьютере: откройте index.html в браузере. Журнал и прогресс сохраняются в хранилище браузера.
2. Для установки на iPhone разместите все файлы этой папки на HTTPS-хостинге (например, GitHub Pages).
3. Откройте адрес в Safari на iPhone → Поделиться → На экран «Домой» → Добавить.
4. Запускайте MyFit с домашнего экрана. Для резервной копии используйте вкладку «Журнал» → «Экспортировать данные».

Файлы: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

ВАЖНО: данные сохраняются локально на устройстве. Если очистить данные сайта / удалить приложение, история может быть утрачена. Экспортируйте резервные копии регулярно. На других устройствах данные не синхронизируются.

Тренировочный план предназначен для здоровых взрослых; нагрузки подбирайте с учётом самочувствия и техники.

MyFit 1.1: карточки упражнений раскрывают видео и технику. Некоторые ролики встроены через YouTube; для остальных доступен поиск соответствующей видеодемонстрации. Интернет необходим для видео.

Версия 1.2: 17 разных упражнений, каждый с тремя подсказками и ссылкой на видео/видеоурок. Некоторые видео открываются во внешнем браузере. Сами видео не включены в архив, нужен интернет.
