MyFit 1.5 — ПИТАНИЕ (обновление для существующего приложения)
===========================================================

ЧТО НОВОГО
• Четвёртая вкладка «🥗 Питание» рядом с «Тренировка», «Журнал», «Прогресс».
• Завтрак, обед, перекус, ужин; продукты, блюда, граммы, фото.
• Расчёт калорий и БЖУ по введённым значениям НА 100 ГРАММ.
• Справочник популярных продуктов, редактирование и удаление записей.
• Суммы по приёмам пищи и дню, история по датам.
• Необязательные личные цели на день.
• Экспорт/восстановление дневника питания С ФОТО в JSON.

ВАЖНО
• НЕ удаляйте приложение с главного экрана iPhone для обновления — можно потерять данные.
• Сначала сохраните старые тренировки через MyFit → Журнал → Экспортировать данные (JSON).
• Само приложение и фотографии/видео упражнений не надо заменять или удалять.
• Встроенный справочник даёт ПРИБЛИЗИТЕЛЬНЫЕ значения БЖУ. Для точности вводите значения с упаковки.
• Калории по фото НЕ распознаются автоматически. Фото прикрепляется к записи в дневнике.
• Дневник хранится локально в том браузере/приложении iPhone, где вы его заполняете.
  Это не облачная синхронизация между устройствами. Регулярно экспортируйте питание в JSON.

УСТАНОВКА НА GITHUB PAGES
1) Откройте репозиторий, где расположен действующий MyFit.
2) Загрузите в корень (рядом с index.html) файл myfit-nutrition.js.
3) Откройте index.html для редактирования и ПОСЛЕ основного скрипта MyFit, в самом конце перед </body>, добавьте:

   <script src="./myfit-nutrition.js?v=15"></script>

   Например, если внизу уже есть строка
   <script src="./myfit-upgrade.js?v=14"></script>
   то новая строка должна идти после неё и перед </body>.

4) Commit changes. Откройте сайт MyFit при подключённом интернете и обновите страницу.
   Внизу появится новая вкладка «🥗 Питание».

ДОПОЛНИТЕЛЬНО: В АРХИВЕ ТАКЖЕ ЕСТЬ myfit-upgrade.js
• Это обновление 1.4 для журнала рабочих весов и 3 подходов (вместо 2 на неделях 1–7).
• Если 1.4 УЖЕ установлена, второй раз файл/строку добавлять НЕ НАДО.
• Если 1.4 ещё НЕ установлена, можно загрузить myfit-upgrade.js рядом с index.html
  и подключить перед скриптом питания:

   <script src="./myfit-upgrade.js?v=14"></script>
   <script src="./myfit-nutrition.js?v=15"></script>

• Менять весь index.html на чужой готовый файл не нужно: это сохранит настройки
  текущей версии с собственными фотографиями, короткими видео и упражнениями.

ПРИМЕЧАНИЕ ОБ ОФЛАЙН-РЕЖИМЕ
Если приложение остаётся старым даже после обновления сайта, возможно,
старую страницу удерживает Service Worker. Сначала откройте сайт онлайн в Safari
и перезагрузите. Для надёжного обновления при необходимости надо поднять версию
кэша в действующем sw.js, не удаляя локальные записи приложения.

КАК ПОЛЬЗОВАТЬСЯ
1) В «🥗 Питание» выберите дату и нажмите «+ Добавить» возле нужного приёма пищи.
2) Выберите продукт в подсказках или введите собственное название и КБЖУ на 100 г.
3) Введите вес порции в граммах; итог пересчитается автоматически.
4) При желании нажмите «Фотография блюда» и выберите фото из галереи или камеры.
5) Нажмите «Сохранить в дневник». Запись появится в выбранном приёме пищи.
6) Нажмите «✎» для изменения или «✕» для удаления.
7) В «История питания» выберите дату для просмотра.
8) Регулярно нажимайте «Экспорт питания»; этот экспорт включает фотографии.

ХРАНЕНИЕ
• Основные тренировки: старый ключ myfit-natalia-v1, обновление НЕ меняет его.
• Питание: отдельный ключ myfit-nutrition-v1 в localStorage.
• Фото: отдельная база IndexedDB myfit-nutrition-photos-v1.
• Удаление браузерных данных, смена устройства/браузера, переустановка PWA могут
  удалить локальные данные. Экспорт JSON — обязательная резервная копия.

Файл myfit-nutrition.js не передаёт фотографии на внешний сервер.
